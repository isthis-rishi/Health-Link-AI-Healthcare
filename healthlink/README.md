# Health Link

Community healthcare web application connecting Patients, Clinics, and Pharmacies with smart symptom assessment, emergency SOS alerts, appointment booking, and prescription management.

## Tech Stack

- Frontend: React.js, Tailwind CSS, Vite
- Backend: Node.js, Express.js
- Database: Firebase Firestore
- Authentication: Firebase Auth
- Hosting: Vercel

## Setup

```bash
cd client
npm install
npm run dev
```

## Features

- Symptom Checker with triage assessment
- Emergency SOS with location sharing
- Appointment booking and management
- Prescription management and validation
- Predictive health analytics
- Payment integration
- Role-based dashboards (Patient, Clinic, Pharmacy)
